============================================================
  DONATIL VISUALS 2.4.1 - исходники мода (Fabric 1.21.1)
============================================================

  Меню модулей: RIGHT SHIFT (открыть / закрыть)
  Закрыть также: ESC
  Включённые модули:
    - FPS HUD          — счётчик FPS
    - Keystrokes       — WASD индикатор + клики
    - Buff Timer       — осталось секунд до конца эффекта
    - Fullbright       — мягкая гамма (по умолчанию выкл.)

════════════════════════════════════════════════════════════
  КАК СОБРАТЬ — НИЧЕГО НЕ СТАВИТЬ НА КОМП
════════════════════════════════════════════════════════════

  Используй GitHub Actions (бесплатно):

  1. github.com -> Sign up (2 мин.)
  2. New repository -> Create.
  3. 'uploading an existing file' -> перетащи ВСЕ файлы
     из этой папки (важно: папка .github тоже нужна).
  4. Commit changes.
  5. Вкладка Actions -> разреши workflows если попросит.
  6. Жди 2-5 минут -> зелёная галочка.
  7. Открой запуск -> Artifacts -> donatil-visuals-jar.
  8. Распакуй -> donatil-visuals-2.4.1.jar -> в .minecraft/mods.

════════════════════════════════════════════════════════════
  КАК ПОСТАВИТЬ МОД
════════════════════════════════════════════════════════════

  1. fabricmc.net -> скачай Fabric Loader под 1.21.1.
  2. Скачай Fabric API с modrinth.com -> .minecraft/mods.
  3. Положи donatil-visuals-2.4.1.jar -> .minecraft/mods.
  4. Запусти профиль Fabric. RIGHT SHIFT -> меню модулей.
